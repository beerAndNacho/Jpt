# ことのは村 · 코토노하 마을

귀여운 마스코트와 함께 매일 조금씩 일본어 단어를 익히는 모바일 우선 웹 학습 서비스.

## 제품 원칙

1. 첫 화면에서 공부 앱보다 작은 게임을 켠 느낌을 준다.
2. 하루 목표는 기본 10단어, 3~5분 안에 끝낼 수 있게 한다.
3. 학습 → 퀴즈 → 복습이 하나의 루프로 이어진다.
4. 틀린 단어는 자동으로 복습 큐에 들어간다.
5. 진행 상황은 XP, 연속 학습일, 마스코트 레벨로 보상한다.
6. 개인정보/로그인 없이 localStorage만으로 먼저 동작한다.
7. 기본 버전은 AI/API 없이 동작한다.

## MVP

- JLPT N5 / N4 단어팩
- 오늘의 10단어
- 카드 학습: 일본어 / 읽기 / 뜻 / 예문
- 브라우저 일본어 음성 읽기
- 4지선다 퀴즈
- 오답 자동 복습
- 간단 SRS: Again / Hard / Good / Easy
- 오늘 학습량 / 전체 숙련도
- 연속 학습일(streak)
- XP와 마스코트 레벨
- 학습 기록 자동 저장
- 모바일 최적화

## 학습 데이터 모델

```js
{
  id: 'n5-neko',
  level: 'N5',
  word: '猫',
  reading: 'ねこ',
  meaning: '고양이',
  example: '猫が好きです。',
  exampleKo: '고양이를 좋아합니다.',
  tags: ['동물']
}
```

사용자 진행도:

```js
{
  wordId: {
    stage: 0,
    dueAt: 0,
    seen: 0,
    correct: 0,
    wrong: 0,
    lastAt: 0
  }
}
```

## 복습 간격

- Again: 지금 세션 후반에 다시 노출
- Hard: 1일
- Good: 3일 → 7일 → 14일 → 30일
- Easy: 단계 2칸 상승
